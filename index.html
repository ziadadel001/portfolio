The parts people never see, but always feel.

gulf/payments

Payment orchestration for Laravel — one API over ten gateways.

I started it after watching the same payment flows get rebuilt from scratch on project after project. Adding a new gateway takes one driver class and one config block.

  • Composable flows — pay now, authorize & capture, deposit with deferred balance, hosted checkout, recurring billing.
  • Built for correctness — idempotency keys, signature-verified and out-of-order-safe webhooks, and a payment state machine that dispatches events only after the DB commit.
  • Testable — a testing fake, a gateway conformance test suite, and PHPStan static analysis.
